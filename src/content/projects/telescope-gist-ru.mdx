Маленький Neovim-плагин, который переносит GitHub Gists в Telescope. Идея простая: открываю Telescope, ввожу часть имени или описания, выбираю гист, предпросматриваю с подсветкой синтаксиса и многофайловые гисты открываются как редактируемые буферы. Изменения синхронизируются с GitHub при `:w`.
