# Просмотр проектов Tmuxinator из терминала

Я написал небольшую shell-функцию, которая позволяет просматривать и запускать проекты `tmuxinator` прямо из терминала, используя `fzf` для интерактивного выбора с превью конфигурации проекта. Это избавляет от необходимости запоминать точные имена проектов или вручную просматривать и запускать сессии `tmuxinator`.

## Функция

```bash
mux-fzf() {
  local workspace config_file
  
  config_file=$(find ~/.config/tmuxinator -name "*.yml" -o -name "*.yaml" 2>/dev/null | \
    fzf \
      --height=40% \
      --reverse \
      --prompt="Select tmuxinator config: " \
      --preview="cat {}" \
      --preview-window=right:60%)
  
  if [[ -n "$config_file" ]]; then
    workspace=$(basename "$config_file" .yml)
    workspace=$(basename "$workspace" .yaml)
    echo "Starting: $workspace"
    tmuxinator start "$workspace"
  fi
}
```
