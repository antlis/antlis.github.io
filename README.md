# antlis.is-a.dev

Personal blog and portfolio website built with [Astro](https://astro.build/).

## Features

- Blog with recent posts
- Portfolio section
- About and Contact pages
- i18n support (English and Russian)
- Dark/Light theme toggle
- RSS feed
- Sitemap generation

## Tech Stack

- [Astro](https://astro.build/) - Static site generator
- [Vue](https://vuejs.org/) - Interactive components
- [MDX](https://mdxjs.com/) - Content authoring
- [astro-expressive-code](https://expressive-code.com/) - Code highlighting

## Development

```sh
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
