# Authoring a blog article

The full, repeatable flow for adding a blog post — including the "fancy" architecture
diagram and the terminal thumbnail. Following this means no re-discovery of conventions.

For a project write-up you produce **six** artifacts: EN post, RU post, EN diagram SVG,
RU diagram SVG, a thumbnail generator entry, and the generated PNG.

## 1. Files & naming

| Artifact | Path |
|----------|------|
| EN post | `src/content/blog/<slug>.mdx` |
| RU post | `src/content/blog/<slug>-ru.mdx` (adds `locale: "ru"`) |
| Thumbnail (hero + card) | `public/blog/<slug>.png` — generated, see §4 |
| Architecture diagram EN | `public/blog/<slug>-architecture.svg` |
| Architecture diagram RU | `public/blog/<slug>-architecture-ru.svg` |

Slug = repo name / kebab topic. EN is un-prefixed (`/blog/<slug>`), RU is `/ru/blog/<slug>`.
Cross-links between the two must use the locale-correct path (RU body links `/ru/blog/...`).

## 2. Frontmatter

Schema lives in `src/content/config.ts` (`blogCollection`). Fields:

```yaml
---
title: "..."
description: "..."           # 1–2 sentences, used for SEO + listing
pubDate: 2026-08-14          # YYYY-MM-DD (a real Date). Today's date for new posts.
modifiedDate: 2026-08-20     # optional, only when materially updated
category: "Linux"            # free string. Seen: Homelab, Shell, Linux
tags: ["rust", "rofi", ...]  # lowercase
imgSrc: "/blog/<slug>.png"   # local PNG (preferred) OR "cloudinary:blog/<slug>"
imgAlt: "..."
locale: "ru"                 # RU file ONLY; EN omits it (defaults to "en")
draft: true                  # optional. draft posts show in `npm run dev`,
                             # are EXCLUDED from production build (src/utils/drafts.ts).
                             # Remove/set false to publish.
---
```

## 3. Body conventions (MDX)

Astro MDX — JSX allowed, use `className` (not `class`).

- **Project metadata block** (the definition-list card at the top of project posts):

  ```jsx
  <dl className="project-meta" aria-label="Project metadata">
    <div><dt>Stack</dt><dd>Rust, tokio, CDP, rofi</dd></div>
    <div><dt>Source</dt><dd><a href="https://github.com/antlis/<repo>">github.com/antlis/<repo></a></dd></div>
    <div><dt>License</dt><dd>MIT</dd></div>
  </dl>
  ```

- **Architecture diagram** (see §5 for the SVG itself):

  ```jsx
  <figure className="architecture-diagram">
    <img src="/blog/<slug>-architecture.svg" alt="<describe the whole flow>" loading="lazy" />
    <figcaption>One-line takeaway.</figcaption>
  </figure>
  ```

  The RU post points at `-architecture-ru.svg`.

- Code fences use expressive-code; ```` ```bash title="..." ```` is supported.
- Voice: precise, understated, "war-stories" concrete (see `tg-mpv-bot.mdx` as the model).
  No marketing tone (see `PRODUCT.md` / `DESIGN.md`).
- **EN/RU parity is required** — write both. Keep structure identical; translate prose.

## 4. Thumbnail (terminal card)

Generated by `blog-thumbnails/generate.mjs` (uses `sharp`, already installed).

1. Add an entry to the `ARTICLES` array:
   ```js
   {
     slug: "<slug>",
     pal: "rust",              // palette preset, see P in the script (rust=orange, shellTeal, mpv, …)
     path: "<slug> — rofi",    // window title-bar text
     lines: [                  // 4–5 lines; {t, c?, size?, bold?, dim?}
       { t: "Tabs: 7", c: "#ffa657", size: 36, bold: true },
       { t: "▌1. GitHub — <slug>", c: "#e6edf3", size: 28 },
       { t: "  - Bookmarks   - History", dim: true, size: 26 },
     ],
   },
   ```
2. Run it from repo root:
   ```bash
   node blog-thumbnails/generate.mjs      # writes public/blog/<slug>.png (1200×760)
   ```
3. Set `imgSrc: "/blog/<slug>.png"`. One image serves both EN and RU, hero and card
   (card crops to a square via CSS, so keep content centered).

## 5. Architecture diagram SVG

Hand-authored, dark, self-contained (renders the same in light/dark). Copy an existing one as
a template — `public/blog/tg-mpv-bot-architecture.svg` or `brave-rofi-rust-architecture.svg`.

Shared style tokens (keep these so all diagrams match):

- `viewBox="0 0 1200 640"`, outer `rect rx="34"` filled with the `#bg` gradient.
- Gradients: `#bg` (`#0f172a → #111827 → accent`), `#panel` (`#1e293b → #0f172a`).
- Box: `class="box"` (`fill:url(#panel);stroke:#334155`). Accent box: stroke `#9a3412`.
- Fonts: `.label` 700 Inter #e5eefb, `.sub` 500 Inter #94a3b8, `.mono` ui-monospace #cbd5e1.
- Arrows: `.line` cyan `#22d3ee` (forward actions), `.return` purple `#a78bfa` (data coming
  back / "raise window"). Each needs a matching `<marker>` (`#arrow` cyan, `#arrowP` purple).
- Labels on arrows: `.tiny` (cyan) / `.tinyp` (purple).
- Always include `<title>`/`<desc>` for a11y, and a descriptive `alt` on the `<img>`.

Preview a diagram to a PNG without a browser:
```bash
node -e "require('sharp')('public/blog/<slug>-architecture.svg',{density:120}).png().toFile('/tmp/c.png').then(()=>0)"
```

## 6. Verify

```bash
npx astro check      # validates frontmatter/schema + types (must be 0 errors)
npm run build        # full build; note: draft:true posts are excluded here
npm run dev          # preview at /blog/<slug> and /ru/blog/<slug> (drafts visible)
```

## 7. Optional follow-ups

- Add a matching entry to the `projects` collection if it's portfolio-worthy
  (`src/content/projects/<slug>.mdx` + `-ru`, different schema — see `config.ts`).
- New blog posts are announced to Telegram post-deploy; state in `social-report.config.json`
  (see `docs/social-report.md`).
